# Frontend Agent Instructions

## Scope
- Applies to `frontend/` only.

## Core Rules
- React + Vite + Tailwind CSS 4.
- Keep UI components in `src/components/` and pages in `src/pages/`.
- Use `@micasa/shared` schemas for shared validation needs.

## Structure
- `src/components/` Reusable UI
- `src/pages/` Route pages
- `src/store/` Redux Toolkit
- `src/services/` API calls
- `src/hooks/` Custom hooks
- `src/utils/` Helpers
- `src/router.jsx` Routes
